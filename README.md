# attari

Marketing site for [attari](https://attari.studio) — a small design studio. Built with Next.js 15, React 19, and Tailwind CSS 4 from Figma.

## Setup

```bash
npm install
```

Add the Season Collection variable font (trial or licensed) as:

```text
public/fonts/SeasonCollectionVF-TRIAL.woff2
```

Download from [Displaay — Season](https://displaay.net/typeface/season/). Only commit the font file if your license allows redistribution.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Works on [Vercel](https://vercel.com) or any Node host that supports Next.js. Ensure the Season font file is present in `public/fonts/` on the deployment environment.
